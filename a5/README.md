# Assignment 5

The following approach is suggested when working with the assignment.

Read the complete document TFE4141_assignment_5_v2.pdfDownload TFE4141_assignment_5_v2.pdf (updates in the "Preparation" list compared to previous version) and perform the steps described under Preparation, including downloading assignment_5.zipDownload assignment_5.zip. Then try to do Task 1. Before starting with Task 2 (unless you are very brave), or even before if you have problems doing Task 1, read document TFE4141_assignment_5_examples.pdfDownload TFE4141_assignment_5_examples.pdf and look at the Vivado-projects implementing the examples. Go through the example code(s), including the testbench(es), and simulate the design(s). Some minor errors are (intentionally) left in the Max of 3 example code for you to detect and correct.

When you have a good understanding of how the example designs work, perform Task 2, 3, and 4 of the assignment. You can assume a protocol for data communication similar to the one used in Assignment 4. Since the system you design is application specific and only performs this single absolute value operation, the system does not use any control from the outside world, except the input_valid signal. If you wish you can add an input signal indicating the start of a new absolute value operation, but then you also need to update the testbench.
